# Interactive map library

A collection of resources and tools for creating beautiful Visuals-standard maps:

- official GL style files for standard Visuals basemaps
- re-usable GL style snippets for map layers (`Motorway`, `LandcoverGrass`, `PlaceCapital`)
- design tokens for map colours and typography (`colors.water`, etc.)

> [!WARNING]  
> This project is in an alpha stage. Expect frequent breaking changes.
